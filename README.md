# bitsperity assets

Public images for bitsperity apps, linked from Nostr events (ideas, banners).
One folder per app. Sources (SVG) live in `<app>/src/`.

| Folder | Content |
|---|---|
| `horizon/` | banner, flow diagram, principles |
| `horizon/landing/` | landing page before and after the Idea Engine rework |
| `horizon/settings/` | Settings before (nine tabs) and after (five sections), signed out, as contact sheets |
| `moonstone/` | banner, signer flow diagram, principles |
| `spero/` | banner, and one avatar per agent of the Spero forest (`<agent>.jpg`, 512×512), drawn by `spero/src/spero_art.py` |
| `ascent/` | banner |
| `beacon/` | banner |
| `canopy/` | banner |
| `kit/` | banner |
| `lunation/` | banner |
| `notus/` | banner |
| `wave/` | banner |
| `weaver/` | banner |

Raw URLs: `https://raw.githubusercontent.com/bitsperity-oss/bitsperity-assets/main/<app>/<file>`

Banners are 1280×720 JPEG covers for Horizon idea cards (16:9, no text or logo).
